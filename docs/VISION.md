# Product Vision: Plant Simulator

A "Plague Inc"-style strategy simulation where the user designs a plant species to conquer a procedurally generated world.

## Target Audience
- Age: 12+ (Educational & Strategic depth).
- Platform: Web Browser (Desktop & Mobile).

## Core Pillars
1. **Scientific Plausibility:** Mechanics based on real biology (Photosynthesis, Nitrogen cycles, Root depth) simplified for gameplay.
2. **Deterministic Simulation:** The world runs on a fixed grid and fixed tick rate.
3. **Visual Feedback:** 4-Quadrant interface showing Macro (Map) and Micro (Cross-section) views simultaneously.
